# Embedded World 2025 SMT32MP2 KAS

kas project configuration used to build the BSP for the Embedded World 2025 demo showing a Flutter GUI communicating with a Zephyr board also from STM32.

## Checkout

```bash
kas checkout
```

Or inside container
```bash
kas-container checkout
```

## Build

```bash
kas build
```

Or inside container
```bash
kas-container build
```
